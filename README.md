# Territory Panel

Sales dashboard for the San Antonio territory — Banner Engineering, Turck, Red Lion Controls, HMS, and PULS.

## Live page

Once GitHub Pages is enabled on this repo (Settings → Pages → Deploy from branch → `main` / root), this dashboard is live at:

`https://<your-username>.github.io/<repo-name>/`

## Updating it each month

1. Open `index.html` in this repo
2. Click the pencil (edit) icon → **Upload files** (or drag the new file in) to replace it with next month's version, **or**
3. Open the live page itself → click **Upload next month's report** → pick the new Excel file → the dashboard updates in your browser. To save that as the new baseline, you'd still need to re-export and re-upload the updated `index.html` here, since GitHub Pages always serves whatever `index.html` currently contains.

## Note on visibility

This repo needs to be **Public** for GitHub Pages to serve it on the free plan. The data in this file (distributor sales, growth, end-customer names) is visible to anyone with the link once published.
